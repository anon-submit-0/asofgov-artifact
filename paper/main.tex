%
%  IT IS NOT OUR \balance CALL.  acmart.cls defaults to `balance=true' and
%  issues \balance itself from \AtEndDocument, so the call further down in
%  this file is redundant and commenting it out changes nothing.  (Verified:
%  identical 1.11176pt with that call removed.)
%
%  ROOT CAUSE.  Read off a \tracingoutput dump of the offending box --
%  \vbox(186.54024+0.0)x241.14749: one PVLDB column wide, and 186.54pt is
%  balance's own computed half-height \@tempdima, not \@colht -- plus a
%  \typeout probe inside \@BAlancecol on the failing page, which reported
%    tempdima=186.54024pt  ht(col1)=186.0pt  oldvsize=626.0pt  colht=1252.0pt
%  balance.sty sizes its two balanced columns by HEIGHT ALONE.  It checks
%  \ht3 against \@tempdima in its split loop, and ships each column as
%    \vbox to \@tempdima{<column material>\vfil}.
%  But that trailing \vfil makes the material's own DEPTH count as height:
%  the last line's descender, which was the box's depth while it was being
%  measured, sits above the \vfil in the box that is actually shipped.  So a
%  column whose height fits by 0.54pt can still overrun its target by the
%  ~1.1pt of depth nobody counted.  Height-only accounting is the bug; it is
%  latent in balance.sty and surfaced here only because routes A and C moved
%  the reference list to a break where the last line carries a descender.
%
%  FIX: reassemble both columns exactly as they will be shipped, then size
%  the pair by max(ht+dp) rather than max(ht), and keep the result bounded by
%  one real column (\oldvsize holds it, because \@BAdblcol has doubled
%  \@colht by this point).  No warning is suppressed, \vfuzz is untouched,
%  and the split point -- hence the CONTENT of both columns -- is unchanged;
%  the balanced columns simply get the ~1pt they always needed, on a page
%  with ~440pt of unused height.  Inert whenever the split lands cleanly, so
%  this stays correct when the reference list changes length again.
%  Verified: overfull 3 -> 0 with the body length,
%  all three content gates and the float and claim counts unchanged.
\newsavebox\rcbalcolone
\newsavebox\rcbalcoltwo
\makeatletter
\renewcommand{\@BAlancecol}{\if@twocolumn
  \setbox0=\vbox{\unvbox\@outputbox} \@tempdima=\ht0
  \advance\@tempdima by \topskip \advance\@tempdima
     by -\baselineskip \divide\@tempdima by 2
     \splittopskip=\topskip
  {\vbadness=\@M \loop \global\setbox3=\copy0
   \global\setbox1=\vsplit3 to \@tempdima
   \ifdim\ht3>\@tempdima \global\advance\@tempdima by 1pt \repeat}
   % reassemble both columns exactly as they will be shipped, then measure
   \setbox\rcbalcolone=\vbox{\unvbox1}%
   \setbox\rcbalcoltwo=\vbox{\dimen2=\dp3\unvbox3\kern-\dimen2}%
   % a \vfil follows the unboxed material, so each column's DEPTH turns into
   % height in the box that is actually shipped -- count ht+dp, not ht
   \@tempdimb=\dimexpr\ht\rcbalcolone+\dp\rcbalcolone\relax
   \ifdim\@tempdimb>\@tempdima \@tempdima=\@tempdimb \fi
   \@tempdimb=\dimexpr\ht\rcbalcoltwo+\dp\rcbalcoltwo\relax
   \ifdim\@tempdimb>\@tempdima \@tempdima=\@tempdimb \fi
   \ifdim\@tempdima>\oldvsize \@tempdima=\oldvsize \fi
   \setbox\@leftcolumn=\vbox to \@tempdima{\unvbox\rcbalcolone\vfil}%
   \setbox\@outputbox=\vbox to \@tempdima{\unvbox\rcbalcoltwo\vfil}%
  \fi}
\makeatother

\begin{abstract}
\looseness=-1 Enterprise analytics increasingly runs through a governed
semantic layer driven by a language model, and the layer moves: calibers are
re-scoped, valid-time anchors re-declared, graph versions advance. Yet
answering a governed question ``as of $T$'' is still treated as a prompting
problem. We show that, on the evidence of a single-statement,
no-execution-feedback protocol, it is a compile-time \emph{binding} problem.
We present \textsc{AsOfGov}: a bi-temporal governed query semantics whose
typed refusals are values, prove that bindability plus three refusal classes
decidably partition well-formed single-period queries, extend compilation
under a disclosure policy to \textsc{Mlr-Compile} (a maximal legal rewrite or
a complete structured refusal), and add point-in-time certificates checked by
a verifier sharing no module with the compiler. On a fully public 60-question
suite, four frontier model families err on 60.0--76.7\% of questions and
three prompt variants on 53.3--66.7\%. Handed its database's entire
governance layer verbatim, a pre-registered arm still errs on 46.7\%, and its
refusal-side errors concentrate where only a data probe decides (6 of 7,
against 1 of 5 on registry-decidable refusals): under this protocol,
in-context governance eliminates only 0.361 of the reference backbone's
errors, short of the frozen $40\%$ line; its frozen 80\% prediction interval
[0.35, 0.75] straddles that $40\%$ line, and crediting every probe-decidable
residual lifts elimination to at most $0.472$, every execution-error residual
as well to at most $0.667$, past that line either way. The compiler resolves
all 60 questions, a constructive upper bound; the verifier accepts 60 of 60
certificates and rejects 34 of 34 forgeries. Verification costs a paired
median $17.7\times$ the answering query it certifies and the certificate
$10.2\times$ the query's bytes.
\end{abstract}
